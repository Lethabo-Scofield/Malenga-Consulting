# Team photos

Drop the photos here with these exact names (JPG, ideally 1600px+ wide):

- `ceo.jpg`  - solo portrait of the Founder & CEO (portrait or square crop works best)
- `team.jpg` - wide group photo of the team

The About page picks them up automatically. Until a file exists, that part of the
section shows a brand placeholder (portrait) or is hidden (group photo).
Set the Founder's name in `src/content/team.ts`.
